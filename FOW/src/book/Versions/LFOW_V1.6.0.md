# LFOW V1.6.0

The LFOW is now UE5.8-friendly! This update introduces new rendering options that give your game a stylized look.

## **Features**

- `Compatibility`: Now supports UE5.8.
- `Optimization`: `SubFogTexture` is now enabled by default.
- `Rendering`: Added a new `Stylized Edge Fog` option to give the fog a cartoon-style appearance.
- `Rendering`: The post-process material now has dedicated `FogColor` and `FogEdgeColor` parameters.

## **Documentation**

- `Post Process`: Added a new `Stylized Edge Fog` section to the documentation.
